# Prior-art survey (2026-10-01)

15 projects cloned to `research/agent-platform-survey/` and reviewed against the design by three reviewers reading the code (file:line evidence), with key claims re-checked.

## Verdicts

| Project | License | Verdict | What we take |
|---|---|---|---|
| agent-wire | AGPL-3.0 | borrow idea | durable outbox with `stored → delivering → submitted / unknown / failed`; restart marks in-flight `unknown`, never retried; idempotency key + fingerprint; `thread/loaded/list` check before Codex delivery |
| agent-loom | MIT | borrow idea | lease owner = pid + process start time, inactivity expiry; per-attempt key separate from idempotency key |
| mcp_agent_mail | MIT + rider | skip | rider grants no rights to anyone acting for Anthropic or OpenAI; only the generic idea of a lease check at publish time |
| cmux | none | skip | Claude only, no resume, auto-approves permission prompts |
| ccgram | MIT | borrow idea (strongest) | delivery receipts: transcript offset advances only after every Telegram send from that item is confirmed (`delivery_contract.py`) |
| ccbot | MIT | borrow idea | persisted per-operation `retry_after` cooldowns instead of sleeping in the call (`telegram_rate_limit.py`); event-loop liveness watchdog; exit on sustained 409; singleton lock; bracketed paste for input |
| tmux-duck | MIT | borrow idea | during a flood, drop status updates and keep content |
| tg-agent-bridge | MIT | skip | its resend-Enter-if-the-prompt-never-appears check is covered by the ccbot input idea |
| tmux-claude-bot | MIT | skip | its restart-surviving queue is covered by work item 2 (ours will be written atomically) |
| claude_codex_bridge | AGPL-3.0 | borrow idea | steer guarded by expected turn id; finer message states (stalled, runtime_dead, dead_letter); Stop hook tied to the exact submission |
| telegram-claude-codex | MIT | skip | one-shot SDK runs, not interactive sessions |
| Tmux-Orchestrator | none | skip | send-keys scripts, no ids, no Codex |
| qmd | MIT | adopt whole for markdown | knowledge search over docs, memory, handoffs, datasheets (§11); for history borrow chunking, weighted fusion, strong-match shortcut, reranker |
| picoqmd | MIT | skip | downloads llama.cpp at runtime; brute-force vector scan |
| jev-gate | MIT | borrow idea | deny hook order: hard rules, then allowlist, then model; "policy can only tighten"; injection-test harness for triage |

## What none of them has

- Codex attached to one shared remote-control daemon, so the ChatGPT app sees the same thread (ours does).
- A durable inbound Telegram spool (persist before advancing the offset).
- One router-wide outbound scheduler.
- Native Telegram rich tables (ours; theirs render MarkdownV2 table cards).
