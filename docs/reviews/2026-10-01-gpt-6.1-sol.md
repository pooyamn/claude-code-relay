The design has two blockers: credential isolation is unenforced, and post-merge resetting can lose work.

1. **Blocker — §6: hooks are not an isolation boundary.** Full-access sessions sharing `pouya` can read broker secrets, modify policy, or call HTTP instead of denied CLIs. The current [sender](/Users/pouya/.openclaw/workspace/scripts/claude-relay-send.py:57) reads the bot-token file identified by transport metadata. [Codex calls hooks guardrails](https://learn.chatgpt.com/docs/hooks#tool-coverage). **Fix:** separate broker identity, protected configuration, session sandboxes, narrowly authenticated action requests, and no broker execution of repository-controlled hooks/scripts.

2. **Blocker — §6a: squash/reset has unsafe mechanics.** [Squashing](https://git-scm.com/docs/git-merge#Documentation/git-merge.txt---squash) loses branch ancestry; resetting the reused branch makes its next push non-fast-forward. A [hard reset](https://git-scm.com/docs/git-reset) discards dirty work and removes newer unpushed commits from the branch. Blocking pushes does not freeze editing. **Fix:** quiesce writers, preserve dirty files and backup refs, replay post-checkpoint commits onto main, and use fresh publication branches or explicit leases across both mirrors.

3. **Major — §6a: review can approve the wrong revision.** Rebasing before merge changes the reviewed head; another session advancing main changes the integration result. A pass/fail comment and router-only merging do not enforce correctness. **Fix:** bind approval to head/base SHAs, invalidate stale passes, independently test the integration candidate, require corresponding checks, and serialize merges per repository.

4. **Major — §§2a/3/7: memory has collisions and contradictory authority.** `NOW-<agent>` collides across tasks; agent and repo MEMORY files have multiple writers. Atomic replacement alone still loses concurrent updates. Outside-tree facts can describe unmerged branches. Decisions overlap company, agent and repo memory without an authoritative copy; company approval authority differs between §§2a/7. **Fix:** session-keyed handoffs, one curator per scope accepting versioned proposals, canonical ownership per fact, provenance/commit scope, freshness rules, and explicit loading/refresh behavior.

5. **Major — §§5/9: delivery guarantees exceed the implementation.** [ccrelayd](/Users/pouya/.openclaw/workspace/scripts/ccrelayd.py:159) advances offsets before handling and queues jobs in RAM. [Codex enqueue/drop](/Users/pouya/.openclaw/workspace/scripts/relay-codex-proto.py:54) can erase concurrent appends; `send()` reports “started” after an unanswered request. Crashing after acceptance but before recording it creates duplicates. **Fix:** transactional inbox/outbox, durable IDs and acknowledgments outside model context, persistence before offset advancement, and idempotent actions. Distinguish accepted, processed and completed.

6. **Major — §§5/6/8: authority and visibility are bypassable.** Native [Claude SendMessage](https://code.claude.com/docs/en/cross-session-messaging) bypasses `agent-msg`, bus logging and hop accounting. Text headers cannot authenticate CTO authority. [Router authorization](/Users/pouya/.openclaw/workspace/scripts/ccrelayd.py:180) permits everyone with an empty allowlist, or any member of allowed chats. **Fix:** mandatory broker routing, authenticated session identities, centrally assigned causal IDs, fail-closed owner authorization, and single-use approvals bound to exact actions.

7. **Major — §4: restart is not recovery.** [Resume failure](/Users/pouya/.openclaw/workspace/scripts/relay-codex-proto.py:324) can fall through to a fresh thread. Reconciliation lacks desired state, ownership leases and unfinished-action recovery; intentional stops can be resurrected. **Fix:** one supervisor, separate desired/observed state, verified boot dependencies, exact-ID resume, and durable turn/action recovery.

8. **Major — §4: agent ownership does not serialize sessions.** Two `pcb-routing` tasks still own the same board. Separate schematic/PCB ownership also misses semantic coupling between those files and the BOM. **Fix:** per-artifact session leases, changed-path checks at publication, and review/test coherent hardware revisions together.

9. **Major — §4: compaction handoff is not guaranteed.** **Wrong as a native guarantee:** `PreCompact` provides no prompt/agent handler to make Claude rewrite a semantic handoff; [hook docs](https://code.claude.com/docs/en/hooks#prompt-based-hooks) establish this. Codex checkpointing is absent. **Fix:** maintain validated handoffs at regular checkpoints in both tools; hooks snapshot them plus Git/filesystem state.

10. **Major — §§3/4: role discovery is incomplete.** **Wrong:** the role’s [.agents/skills](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) directory outside Codex’s worktree/user discovery paths will be missed. Generated rule copies also stale after rebases. Linked worktrees have a [.git file](https://git-scm.com/docs/git-worktree#_details), not the proposed exclude directory. **Fix:** wire role skills into worktrees, refresh generated rules, and resolve excludes with `git rev-parse --git-path info/exclude`.

11. **Major — §8: traffic can starve control messages.** The group limit is **verified** ([Telegram FAQ](https://core.telegram.org/bots/faq#my-bot-is-hitting-limits-how-do-i-avoid-this)); independent [429 retries](/Users/pouya/.openclaw/workspace/scripts/relay_tg.py:58) provide no shared scheduling. **Fix:** one priority outbox, chat/bot throttles, coalesced progress, reserved control capacity and persisted final replies. Define the offline limit: [updates expire after 24 hours](https://core.telegram.org/bots/api#getting-updates).

12. **Major — §§6a/7: review rhythm amplifies usage.** Every checkpoint needs reviewer/CTO turns; one reviewer bottlenecks sessions, and always-loaded DECISIONS grows indefinitely. **Fix:** keep publications reviewed, batch coherent checkpoints, encode CTO-approved routine merge policy, bound concurrency, and load historical decisions on demand.

13. **Minor — §§2–5: product contracts need validation.** **Verified:** Claude ≥2.1.277 AGENTS support, user imports, additional-directory loading, auto-memory switch and ignoring overrides ([memory docs](https://code.claude.com/docs/en/memory)); native inbox/loop throttling ([messaging docs](https://code.claude.com/docs/en/cross-session-messaging)); Codex remote/queue, enabled hooks and disabled memories (installed help/features), and [override precedence](https://learn.chatgpt.com/docs/agent-configuration/agents-md). **Wrong:** blanket five-minute holding; bypass→bypass delivers by default. **Unverifiable:** socket posting envelope, daemon ignoring developer overrides, absent Codex loop guards, and wrapper urgent mapping. **Fix:** pin/test adapters; queue help exposes no urgent/steer option, while [turn/steer is documented](https://learn.chatgpt.com/docs/app-server#steer-an-active-turn).
