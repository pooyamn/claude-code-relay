1. **Blocker — §6: the enforcement boundary does not exist.** With the [current full-access policy](/Users/pouya/.openclaw/workspace/scripts/relay-codex-proto.py:316) and one OS user, sessions can bypass command-name hooks with scripts, alter shared files, or access router credentials. The existing [relay reads the Telegram token itself](/Users/pouya/.openclaw/workspace/scripts/claude-relay-send.py:57). **Fix:** isolate the credential broker under another OS principal and sessions from each other; provide restricted filesystem/network access and authenticated action requests. Resolve §6’s human-approval requirement versus §6a’s automatic merges explicitly.

2. **Blocker — §6a: reset can discard legitimate work.** “No new push” still allows local commits and dirty/untracked files during review. Hard reset can destroy changes; retaining remote branch refs after squash/reset makes subsequent pushes non-fast-forward. Resetting a checked-out branch elsewhere also races its worktree. **Fix:** quiesce the owning session, preserve committed/uncommitted work, fetch merged main, and replay only post-review work. Prefer fresh checkpoint branches; otherwise synchronize main and use expected-old-SHA leases when rewriting both mirrors. [Git reset](https://git-scm.com/docs/git-reset), [worktrees](https://git-scm.com/docs/git-worktree).

3. **Major — §6a: review does not authorize the eventual merge.** Rebasing after approval changes the reviewed commit; another session can advance main between validation and merge. A PR comment saying “pass” is not an enforced check. **Fix:** serialize integration per repository, bind reviewer verdicts and independently executed tests to exact head/base SHAs, and invalidate them after changes. Give the router no bypass of those gates.

4. **Major — §§4,9: recovery can create two writers.** Existing [lock recovery deliberately unlinks a live daemon’s lock](/Users/pouya/.openclaw/workspace/scripts/relay-codex-proto.py:415); observing idleness does not prevent subsequent activity. Non-lock resume errors also fall through to creating a fresh thread. Tool switching lacks a stop-and-transfer protocol. **Fix:** use one daemon, explicit ownership handover and durable session generations; never steal a live lock. Reconcile actual turns and child processes after restart, preserving paused/stopped state before resuming.

5. **Major — §§5,9: “delivered” is underspecified and lossy.** [Offsets advance before dispatch](/Users/pouya/.openclaw/workspace/scripts/ccrelayd.py:158); [queue deletion races append](/Users/pouya/.openclaw/workspace/scripts/relay-codex-proto.py:81); [send treats timeout as success](/Users/pouya/.openclaw/workspace/scripts/relay-codex-proto.py:507). Finished replies are [consumed before Telegram acknowledgment](/Users/pouya/.openclaw/workspace/scripts/claude-relay-send.py:2570). Receiver deduplication cannot depend on model memory. **Fix:** transactional inbox/outbox, durable IDs, acknowledgments distinguishing accepted/completed, idempotent actions, and reconciliation of uncertain outcomes. Never blindly repeat payments or merges.

6. **Major — §§2a,4,7: memory lacks single writers and validity boundaries.** Multiple sessions share agent memory and overwrite `NOW-<agent>.md`; all repo sessions race on MEMORY.md. Unmerged observations become global “facts”; company/role/repo decisions can contradict each other. Agent/repo MEMORY.md have no explicit loading or refresh contract. **Fix:** session-ID handoffs, one curator per canonical file, append-only proposals, provenance/date/commit scope, precedence and bounded loading. Binary-file ownership also needs session leases.

7. **Major — §4: the compaction guarantee is wrong.** Claude’s [PreCompact](https://code.claude.com/docs/en/hooks#prompt-based-hooks) supports neither prompt nor agent hooks: it cannot simply make Claude write a handoff. Crashes bypass it; Codex has no handoff path specified. **Fix:** checkpoint task state during normal turns in both tools; hooks snapshot structured state, and startup verifies freshness against HEAD and pending actions.

8. **Major — §§3–4: launcher paths are wrong.** A [linked worktree’s `.git` is a file](https://git-scm.com/docs/git-worktree#_details), making `.git/info/exclude` invalid; resolve it through `git rev-parse --git-path info/exclude`. Role-local skills outside the worktree fall outside [Codex’s discovery paths](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills). Generated overrides retain stale repo rules after HEAD changes. **Fix:** expose skills in discovered locations and regenerate/reload instructions after integration. Place worktrees outside the main checkout to avoid also loading its ancestor Claude instructions.

9. **Major — §§5,8: identity and visibility can be bypassed.** Header filtering cannot authenticate senders or stop native messaging bypassing the bus; “most recent session” can route an actionable message to the wrong task. **Fix:** broker-issued identities, immutable destination/thread IDs, broker-owned hop counts, and mediation of every transport.

10. **Major — §8: splitting groups is insufficient flow control.** The 20/minute group limit is **verified** by [Telegram](https://core.telegram.org/bots/faq#my-bot-is-hitting-limits-how-do-i-avoid-this), but independent watchers still compete. **Fix:** one outbound scheduler with per-chat/bot budgets, coalesced status, approval priority and durable `retry_after` handling. Inbound updates survive only [24 hours](https://core.telegram.org/bots/api#getting-updates).

11. **Minor — §§6a,7: unnecessary review/context amplification.** Each successful checkpoint adds model review, a CTO turn and reset; unbounded DECISIONS.md loads everywhere. **Fix:** distinguish backup pushes from explicit review checkpoints, cache verdicts by head/base SHAs, cap subscription concurrency, and load a decision digest with links. Every main change still receives independent review.

12. **Minor — §§2–5: capability claims need a versioned contract.** **Verified:** installed Claude 2.1.287; [native AGENTS.md, memory toggle, imports/add-dir](https://code.claude.com/docs/en/memory); Codex help confirms remote/queue/resume, features reports hooks on/memories off; [override precedence](https://learn.chatgpt.com/docs/agent-configuration/agents-md). Claude inboxes/throttling are **verified**; blanket five-minute expiry is **wrong**: [bypass-to-bypass delivers by default](https://code.claude.com/docs/en/cross-session-messaging). **Unverifiable here:** script socket payload, `agent-msg --urgent` mapping, Codex loop throttling, daemon ignoring developer instructions. **Fix:** record versioned evidence; `queue --help` has no urgent flag.

First three changes: isolate the credential broker; make review/integration transactional and bound to SHAs; implement durable delivery and exclusive session ownership.
